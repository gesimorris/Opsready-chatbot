# OpsReady MCP Agent

A capstone project built in collaboration with OpsReady,
an operations management software for industrial work. Our team designed and developed an AI-powered 
assistant that allows OpsReady clients to query and analyze their operational 
data through natural language — eliminating the need for manual data inspection.

## My Role
- Built the Phase 2 frontend and FastAPI backend independently after the capstone
- Integrated Claude Sonnet via the Anthropic API to power the chat interface
- Designed the conversation history system for stateless LLM context management
- Developed the voice input tool as well as several others

## Features
- Natural language querying of operational data
- 14+ tools covering tasks, work orders, deficiencies, assets, and user logins
- Stateless conversation history passed per request for continuous AI dialogue
- CORS configured for secure cross-origin frontend/backend communication
